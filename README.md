# 🛋️ Furni - Furniture Website

A modern and responsive furniture e-commerce website designed to provide a clean and user-friendly shopping experience.

## 🌐 Project Overview

**Furni** is a furniture website where users can explore different furniture products, view product information, manage their cart, and proceed through the checkout process.

The project focuses on a clean UI, responsive design, and simple navigation.

## ✨ Features

* 🏠 Modern Home Page
* 🛋️ Furniture Product Showcase
* 🛒 Shopping Cart
* 💳 Checkout Page
* 📦 Product Shop Page
* 👥 About Us Page
* 🛠️ Services Page
* 📝 Blog Section
* 📞 Contact Page
* 📱 Fully Responsive Design
* 🎨 Modern and Clean UI
* ⚡ Interactive JavaScript Components

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript
* SCSS
* Tiny Slider

## 🚀 How to Run

No installation or build process is required.

### Step 1

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/furni-furniture-website.git
```

### Step 2

Open the project folder:

```bash
cd furni-furniture-website
```

### Step 3

Open `index.html` in your browser.

You can also use **VS Code Live Server** for easier development.
